# AdStudio Ali Al-Zghoul
واجهة عربية أولية لإنشاء معاينات إعلانات المنتجات.

## التشغيل
افتح `index.html` في متصفح حديث.

## الميزات الحالية
- واجهة عربية RTL متجاوبة.
- رفع صورة المنتج ومعاينتها محليًا.
- اختيار مقاس الإعلان.
- إنشاء نص إعلاني مقترح ونسخه.

## ملاحظة
هذه نسخة واجهة أولية. توليد الصور والفيديو بالذكاء الاصطناعي يتطلب ربط خدمة أو نموذج عبر خادم آمن. لا تضع مفاتيح API السرية في ملفات المتصفح.

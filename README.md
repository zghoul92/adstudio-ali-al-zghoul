# AdStudio Ali Al-Zghoul

منصة عربية RTL لإنشاء صور إعلانية للمنتجات. الواجهة مستضافة عبر GitHub Pages، ومحرك توليد الصور مفتوح المصدر موجود في مجلد `hf-space/` لتشغيله على Hugging Face Spaces.

## رابط الموقع

https://zghoul92.github.io/adstudio-ali-al-zghoul/

## ما يعمل في الواجهة

- رفع صورة المنتج ومعاينتها محليًا.
- اختيار المقاس والأسلوب ووصف المشهد.
- الاتصال بمحرك Gradio بعد نشر Hugging Face Space وإدخال رابطه.
- عرض صورة التوليد وتنزيلها.
- إعدادات المحرك تحفظ محليًا في المتصفح فقط.

## تشغيل الذكاء الاصطناعي

1. افتح [مجلد hf-space](https://github.com/zghoul92/adstudio-ali-al-zghoul/tree/main/hf-space).
2. اتبع خطوات النشر في [hf-space/README.md](hf-space/README.md) لإنشاء Gradio Space ورفع `app.py` و`requirements.txt`.
3. انتظر اكتمال بناء Space وتنزيل أوزان النموذج.
4. افتح الموقع، وسّع «إعداد محرك الذكاء الاصطناعي»، ثم ألصق رابط Space واحفظه.
5. ارفع صورة واكتب وصفًا واضغط «توليد صورة الإعلان بالذكاء الاصطناعي».

## النموذج

- Stable Diffusion XL Img2Img.
- IP-Adapter لتوجيه التوليد اعتمادًا على صورة المنتج المرجعية.
- Hugging Face Diffusers + Gradio.

النتائج قد تغير التفاصيل الصغيرة مثل الشعارات والكتابات؛ راجع صورة المنتج قبل نشر الإعلان. راجع شروط تراخيص النماذج قبل الاستخدام التجاري.

## الاستضافة والتكلفة

GitHub Pages مجاني للواجهة فقط ولا يشغّل نموذج الذكاء الاصطناعي. قد يتوفر تشغيل GPU مجاني محدود على Hugging Face ZeroGPU للحسابات المؤهلة، لكنه محدود يوميًا ولا يضمن خدمة إنتاجية مستمرة. استضافة GPU مخصصة مدفوعة؛ تحقق من السعر الحالي في إعدادات Space قبل اختيار العتاد. لا تضع أي رمز وصول سري داخل `index.html`.
